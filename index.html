Tron Tools

Mainnet · read-only unless you paste a key · everything runs in your browser

Generate Wallet

Creates a brand-new TRX account in your browser. Nothing is sent anywhere. Save the private key — if you lose it, the funds are gone.

Store the private key in an offline password manager. Anyone with this key controls the funds.

Validate Address

Checks if a string is a syntactically valid Tron address (Base58 T... or 41-hex).

Check Balance

Live TRX + USDT (TRC-20) balance for any address, via TronGrid mainnet.

Transaction Lookup

Paste a 64-char tx hash to see confirmation, block, fee, and transfer details.

Account Resources

Energy, bandwidth, frozen TRX, and votes for an address.

TRX / USD Converter

Live TRX price via CoinGecko. Manual refresh.

Multi-Address Balance Checker

Paste one address per line. Shows TRX + USDT for each.

Generic TRC-20 Token Info

Paste a TRC-20 contract address, optionally an owner address for balance.

Network Stats

Current block height, witness count, and chain parameters.

QR Code for Address

Generate a scannable QR for any Tron address, with optional TRX amount.
